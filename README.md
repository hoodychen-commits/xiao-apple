# 小蘋果團購 🍎

> 簡約可愛風格的團購電商網站，前台購物 + 後台管理，Firebase 雲端資料庫，GitHub Pages 免費託管。

## 🌐 網站連結

**前台：** https://hoodychen.github.io/xiao-apple

**後台：** https://hoodychen.github.io/xiao-apple/admin/

---

## ✨ 功能

### 前台
- 商品列表瀏覽
- 商品詳情 + 觀看次數追蹤
- 下單表單（姓名、手機、地址）
- 付款方式選擇（刷卡 / 銀行轉帳）

### 後台
- Firebase Auth 帳號密碼登入
- 商品上架管理（新增/編輯/刪除/上傳圖片）
- 訂單管理（查看詳情、更新狀態）
- 數據儀表板（每日/每月營業額、訂單狀態分佈、熱門商品）

---

## 🛠 技術架構

| 項目 | 技術 |
|------|------|
| 前端 | HTML5 + Vanilla CSS + JavaScript |
| 資料庫 | Firebase Firestore |
| 身份驗證 | Firebase Authentication |
| 圖片儲存 | Firebase Storage |
| 主機 | GitHub Pages |

---

## ⚙️ 設定說明

1. 複製 `js/firebase-config.js` 並填入你的 Firebase 設定
2. 在 Firebase Authentication 建立管理員帳號
3. Push 到 GitHub 並開啟 Pages
